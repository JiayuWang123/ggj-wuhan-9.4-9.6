## 环境要求

| 项目 | 版本 |
|------|------|
| **Unity** | **2022.3 LTS**（请全队统一此版本，避免工程冲突） |
| 协作 | Git + GitHub |

> 用 Unity Hub 安装 **2022.3.x LTS**，打开项目时若提示升级引擎，先和队友确认，不要擅自升级。

---

## 队友克隆仓库

```bash
git clone https://github.com/<你的GitHub用户名>/ggj武汉9.4_9.6.git
cd ggj武汉9.4_9.6
```

用 Unity Hub → **Add** → 选择含 `Assets` 文件夹的工程目录 → **Open**。

---

## 协作约定（Jam 期间建议）

1. **先 pull 再改**，改完及时 **commit + push**
2. 大改 / 动场景前在群里说一声，避免同时改同一文件
3. 美术资源放 `Assets/Art/`，脚本放 `Assets/Scripts/`，场景放 `Assets/Scenes/`
4. 不要提交 `Library/`、`Temp/`、`Logs/`（已在 `.gitignore` 中忽略）
